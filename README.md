# Tilawah Recitation Circle

Tilawah helps Qur'an students submit audio recitations and receive thoughtful feedback from their tutors.

## Local setup

1. Run `mix setup` to install dependencies and prepare the database.
2. Start the application with `mix phx.server`.
3. Visit [localhost:4000](http://localhost:4000).

Configure SMTP credentials through environment variables when enabling delivery emails. Copy `.env.example` as a reference; never commit a real `.env` file.
